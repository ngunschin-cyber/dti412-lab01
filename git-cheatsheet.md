# Git Command Cheat Sheet

## Check Git Version
`git --version` - Shows the installed Git version.

## Configure Username
`git config --global user.name "Your Name"` - Sets your Git name.

## Configure Email
`git config --global user.email "you@email.com"` - Sets your Git email.

## Display Configuration
`git config --list` - Shows your Git settings.

## Clone a Repository
`git clone repository-url` - Downloads a repository.

## Check Status
`git status` - Shows the status of your files.

## Add Files
`git add .` - Prepares changed files for a commit.

## Commit Changes
`git commit -m "message"` - Saves your changes locally.

## Push to GitHub
`git push` - Uploads your committed changes to GitHub.

## Download Updates
`git pull` - Downloads changes from GitHub.

## View Commit History
`git log --oneline` - Shows a short commit history.
